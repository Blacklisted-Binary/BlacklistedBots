## 🚀 Quick Start (Five-Minute Infiltration)

### One-command install

```bash
curl -fsSL https://raw.githubusercontent.com/HKUDS/OpenHarness/main/scripts/install.sh | bash
```

### Install from source

```bash
git clone https://github.com/HKUDS/OpenHarness.git
cd OpenHarness
uv sync --extra dev
```

### Launch

```bash
oh
# or
uv run oh
```

### First setup flow

```bash
uv run oh setup
```
